# RegimeLab API

Start the API:

```bash
uvicorn app.main:app --reload
```

The API reads local cached data and artifacts generated by the CLI pipeline. Training, HMM analysis, and forward-return analysis remain CLI/report workflows, not API endpoints. If `reports/regimelab.db` contains an active experiment with a valid artifact path, the API uses that model; otherwise it falls back to `reports/experiments.json`.

## Endpoints

### `GET /health`

Returns API status and latest model availability.

```bash
curl http://localhost:8000/health
```

### `GET /regime/{ticker}`

Returns the latest predicted regime for a ticker using the latest valid completed experiment.

```bash
curl http://localhost:8000/regime/SPY
```

### `GET /history/{ticker}`

Returns recent historical rule labels, selected signals, and predicted regimes when a model exists.

```bash
curl "http://localhost:8000/history/SPY?limit=20"
```

Optional query parameters:

- `start_date`
- `end_date`
- `limit`: defaults to the latest `100` rows and is capped at `1000`

Rows are returned in chronological order after filtering and limiting. The response includes `count`, `total_available`, and `warnings`.

### `GET /metrics`

Returns metrics for the latest or requested experiment.

```bash
curl http://localhost:8000/metrics
curl "http://localhost:8000/metrics?experiment_id=latest"
```

### `GET /experiments`

Lists recorded training runs.

```bash
curl http://localhost:8000/experiments
```

Optional query parameters:

- `limit`
- `model_type`
- `ticker`

### `GET /reports/hmm/latest`

Returns the latest HMM analysis report JSON generated by the CLI pipeline.

```bash
curl http://localhost:8000/reports/hmm/latest
```

Returns `404` if no HMM report has been generated yet.

### `GET /reports/forward-returns/latest`

Returns the latest forward-return regime analysis report.

```bash
curl http://localhost:8000/reports/forward-returns/latest
```

### `GET /reports/walk-forward/latest`

Returns the latest walk-forward validation report.

```bash
curl http://localhost:8000/reports/walk-forward/latest
```

### `GET /reports/model-comparison/latest`

Returns the latest model comparison report.

```bash
curl http://localhost:8000/reports/model-comparison/latest
```

### `GET /reports/explain/latest`

Returns the latest model explanation/explainability report.

```bash
curl http://localhost:8000/reports/explain/latest
```

All report endpoints return `404` with a descriptive `detail` message when no matching report file exists. These endpoints are read-only and never trigger report generation.
